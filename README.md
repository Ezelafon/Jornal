# Jornal

V0 móvil para registrar actividades operativas diarias.

## Alcance V0
- Login con Supabase Auth
- Una sola pregunta: ¿Qué hiciste hoy?
- Registro del relato original
- Lista de actividades del día
- Datos aislados en tablas `jornal_*`

## Criterio de éxito
8 usuarios reales durante una semana laboral, con carga cotidiana y consulta del coordinador sin depender de WhatsApp.

## Deploy
Proyecto Vite/React listo para importar en Vercel. Build command: `npm run build`. Output: `dist`.
